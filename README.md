# Gym Bro

A responsive gym landing page built with React, TypeScript, and Vite.

## Getting started

```sh
npm install
npm run dev
```

## Checks and preview

```sh
npm run lint
npm run build
npm run preview
```

## Features

- Responsive home page with programs, gym information, and membership plans.
- Light/dark theme toggle and mobile navigation.
- Monthly and annual membership price switch.
- Animated hero activity highlights and equipment ticker.
- Reduced-motion support.

## Before launch

- Hero activity counts are sample copy and are not connected to live gym attendance.
- Membership links currently open an email to `hello@gymbro.com`; replace this with the gym's confirmed contact or signup flow before launch.
- Photos and web fonts load from Unsplash and Google Fonts, so they require an internet connection.
